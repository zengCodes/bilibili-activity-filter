# B站活动筛选工具

一个纯前端的B站投稿活动筛选工具，帮助你快速找到适合自己视频类型的活动，不错过流量和奖金。

## 功能特性

- **40+ 活动数据**：内置当前B站有奖活动中心的全部活动
- **多维度筛选**：按分类、剩余时间、奖励类型、参赛门槛筛选
- **关键词搜索**：搜索活动名称、标签、描述
- **智能匹配**：输入你的视频类型，自动计算每个活动的匹配度
- **多种排序**：按截止时间、匹配度、奖励丰厚程度排序
- **活动详情**：点击卡片查看投稿指引、奖励说明、适合的视频类型
- **即将截止提醒**：剩余7天内的活动自动标记"即将截止"

## 使用方法

1. 直接用浏览器打开 `index.html` 即可使用，无需安装任何依赖
2. 在"我的视频类型"输入框中输入你的视频主题（如：影视解说、生活vlog、美食制作）
3. 使用筛选面板缩小范围，找到最适合的活动
4. 点击活动卡片查看详细投稿指引
5. 点击"前往活动页面"跳转到B站活动页投稿

## 数据更新

活动数据手动维护在 `data.js` 中，建议每周更新一次：

1. 访问 [B站有奖活动中心](https://www.bilibili.com/blackboard/era/reward-activity-list-page.html#/list)
2. 查看最新活动列表
3. 在 `data.js` 的 `ACTIVITIES` 数组中添加/更新活动对象

### 活动数据字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 唯一ID |
| title | string | 活动名称 |
| category | string | 分类：综合/游戏/影视/音乐/知识/动画/亲子/科技/鬼畜/品牌 |
| tags | string[] | 活动标签 |
| startDate | string | 开始日期 YYYY-MM-DD |
| endDate | string | 结束日期 YYYY-MM-DD |
| rewardType | string | 奖励类型：现金瓜分/固定奖金/流量扶持/游戏道具/周边抽奖/混合 |
| rewardDesc | string | 奖励详细描述 |
| submitZone | string | 投稿分区 |
| submitTag | string | 投稿话题标签 |
| url | string | 活动页面链接（可选） |
| difficulty | string | 参赛门槛：低/中/高 |
| competition | string | 竞争烈度：低/中/高 |
| suitableFor | string[] | 适合的视频类型标签（用于匹配度计算） |
| desc | string | 活动简介 |

## 筛选技巧

### 新手/小UP主推荐
- 筛选"参赛门槛 = 低"，优先选择投稿即参与的活动
- 选择"现金瓜分"类型，有播放量就有机会分到奖金
- 关注"流量扶持"活动，获得曝光推荐

### 内容质量高的UP主
- 选择"固定奖金"类型活动，奖金更丰厚
- 参与长期活动（>30天），有充足时间打磨内容
- 关注竞争烈度"低"的活动，更容易获奖

### 快速投稿
- 按"截止时间（近→远）"排序，优先处理即将截止的活动
- 筛选"本周截止"，抓住最后的投稿机会
