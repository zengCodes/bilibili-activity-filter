# B站活动筛选工具

一个B站投稿活动筛选工具，**实时获取**B站活动中心最新活动数据，帮助你快速找到适合自己视频类型的活动，不错过流量和奖金。

## 功能特性

- **实时数据获取**：通过后端代理自动从B站API获取最新活动（173+活动），无需手动维护
- **1小时智能缓存**：减少API调用，首次加载后秒开
- **多维度筛选**：按分类、剩余时间、奖励类型、参赛门槛筛选
- **关键词搜索**：搜索活动名称、标签、描述
- **智能匹配**：输入你的视频类型，自动计算每个活动的匹配度
- **多种排序**：按截止时间、匹配度、奖励丰厚程度排序
- **活动详情**：点击卡片查看投稿指引、奖励说明、适合的视频类型
- **即将截止提醒**：剩余7天内的活动自动标记"即将截止"
- **离线fallback**：后端未启动时自动使用本地缓存数据

## 快速开始

### 方式一：启动后端（推荐，实时数据）

```bash
# 安装依赖
npm install

# 启动服务
npm start
```

启动后访问：**http://localhost:3000**

### 方式二：纯前端（离线数据）

直接用浏览器打开 `index.html`，使用本地缓存的40个活动数据。

## 使用方法

1. 启动后端后访问 http://localhost:3000
2. 页面自动从B站获取最新活动数据（约173个）
3. 在"我的视频类型"输入框中输入你的视频主题（如：影视解说、生活vlog、美食制作）
4. 使用筛选面板缩小范围，绿色边框 = 高度匹配的活动
5. 点击活动卡片查看详细投稿指引
6. 点击"前往活动页面"跳转到B站活动页投稿
7. 点击右上角"🔄 刷新数据"可强制从B站重新获取最新活动

## 后端API

| 接口 | 说明 |
|------|------|
| `GET /api/activities` | 获取活动列表（带1小时缓存） |
| `GET /api/refresh` | 清除缓存，下次请求重新获取 |
| `GET /` | 静态文件服务（前端页面） |

### 数据来源

B站活动API：`https://api.bilibili.com/x/activity_components/video_activity/hot_activity`

后端自动分页获取全部活动（每页50条，共4页），并进行数据清洗和格式转换：
- Unix时间戳 → 可读日期
- 标签 → 自动推断分类、奖励类型、参赛门槛
- 活动名称 → 自动推断适合的视频类型

## 筛选技巧

### 新手/小UP主推荐
- 筛选"参赛门槛 = 低"，优先选择投稿即参与的活动
- 选择"现金瓜分"类型，有播放量就有机会分到奖金
- 关注"流量扶持"活动，获得曝光推荐

### 内容质量高的UP主
- 选择"固定奖金"类型活动，奖金更丰厚
- 参与长期活动（>30天），有充足时间打磨内容
- 关注竞争烈度"低"的活动，更容易获奖

### 快速投稿
- 按"截止时间（近→远）"排序，优先处理即将截止的活动
- 筛选"本周截止"，抓住最后的投稿机会

## 技术栈

- **前端**：纯 HTML + CSS + JavaScript，零依赖
- **后端**：Node.js + Express，代理B站API解决CORS跨域
- **缓存**：内存缓存，默认1小时
- **响应式设计**：支持移动端

## 常见问题

**Q: 为什么显示"离线数据"？**
A: 后端服务未启动。运行 `npm start` 启动后刷新页面即可获取实时数据。

**Q: 如何修改缓存时间？**
A: 编辑 `server.js` 中的 `CACHE_DURATION` 变量，单位毫秒。

**Q: 端口被占用怎么办？**
A: 启动时指定端口：`PORT=8080 npm start`

**Q: 活动数据多久更新一次？**
A: 后端缓存1小时，点击"刷新数据"按钮可强制更新。B站活动中心本身每天都可能有新活动。
