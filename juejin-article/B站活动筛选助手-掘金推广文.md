# B站 173 个投稿活动看到眼瞎？我写了个扩展，主打一个精准打击

> 事情是这样的：我盯着 B站活动中心那 173 个活动的列表，翻了四屏之后，终于理解了《一拳超人》里那句台词——"我变强了，也变秃了"。
>
> 问题是，我只是变秃了。

---

## 一、起因：教练，我想拿奖金

先说个扎心的事实：**B站活动中心的列表页，是真的长。**

173 个活动，从「夏日美食季」一路排到「某某品牌联名」，中间还夹着一堆周期长到我已经忘了它存在的长期活动。作为一个做影视解说的十八线 UP，我每周的实操流程是这样的：

1. 打开活动列表页
2. 从第一屏滑到不知道第几屏
3. 眼睛发酸，随手点进一个看着顺眼的
4. 点进去才发现——**「仅限游戏区」**
5. 返回，重来

整套流程走完，我感觉自己像《咒术回战》里被「无量空处」灌了一脑袋信息的普通人：**信息量拉满，但没有一条是我要的。**

那一刻我脑子里响起的，是《灌篮高手》里三井寿那句经典台词——

> **"教练，我想打篮球。"**

我当场改了一个字：

> **"教练，我想拿奖金。"**

于是就有了这个项目：**B站活动筛选助手**。

## 二、它到底是个啥

一句话版本：**在你打开 B站活动列表页的那一刻，把 173 个活动重新排成"适合你"的样子。**

它现在就是一个 Edge 扩展，装了就能用，没有别的步骤。

核心能力就四件事：

- **实时数据**：从 B站 官方接口拉最新活动，173+ 条，1 小时自动更新一次
- **六重筛选**：分类 / 剩余时间 / 奖励类型 / 参赛门槛 / 关键词 / 匹配度
- **智能匹配**：输入你的视频类型，自动算出每个活动的匹配度，高匹配的直接绿框高亮
- **截止提醒**：7 天内截止的活动自动打上「即将截止」标记

听起来像功能列表？别急，我给你演示一下它"打仗"的样子。

### 痛点长这样

以前的我：

![痛点](./assets/02-pain.png)

173 个活动糊在脸上，属于是「赛博溺水」。

### 匹配长这样

选好「我的视频类型」之后：

![智能匹配](./assets/03-match.png)

绿色边框 = 高度匹配。**这不是筛选，这是点名。**

用一句《咒术回战》的话说，这叫——

> **领域展开。**

只不过五条悟展开的是无量空处，我展开的是「影视解说领域」，进来的活动被自动过滤，不相关的全部灰掉。

### 倒计时长这样

![即将截止](./assets/04-deadline.png)

7 天内截止的活动会被标红，避免你在"我明天再投"的循环里错过一波奖金——毕竟**明天是不会来的**。

> 顺便说个彩蛋：某些"唱跳、rap、篮球"相关的分区活动，会被自动打上一个 🏀 专属徽章。具体是谁我就不点名了，懂的都懂。

## 三、装它：30 秒，比泡面还快

### 方式一：Edge 加载项商店（推荐）

点击这个链接，直接在 Edge 加载项商店一键安装：

```text
https://microsoftedge.microsoft.com/addons/detail/cgecpefaijldaikaepdebafgghoaljle
```

或者打开 Edge，访问 [Edge 加载项商店](https://microsoftedge.microsoft.com/addons/)，搜索 **「B站活动筛选助手」**，点「获取」→ 确认。

装完之后，访问 B站活动列表页：

```text
https://www.bilibili.com/blackboard/era/reward-activity-list-page.html
```

你会看到页面顶部多出来一条工具栏——**那一刻，命运的齿轮开始转动。**

> 顺便：点扩展图标还能打开 popup，里面有「即将截止」的快速列表，以及一个"打开活动页面"的传送门。

### 为什么只上架了 Edge？

不是偏爱，是**算过账**：

- **Edge 加载项商店不收开发者注册费**，Chrome 网上应用店需要一次性注册费；
- Edge 商店的审核流程对个人开发者更友好，上架更快；
- 反正都是 Chromium 内核，**同一份代码，一行都不用改**。

对一个"先做出来验证有没有人用"的小工具来说，这个选择相当划算。

### 方式二：Chrome 用户的三步"搬家法"

Chrome 里直接打开 Edge 商店是装不上的（会提示"无法从此网站添加扩展"）。但既然是同一个内核，我们可以把它"搬"过去：

1. **先在 Edge 里装一遍**，装完后完全退出 Edge；
2. 打开这个目录，找到对应扩展 ID 的文件夹（里面还有一层版本号目录）：

```text
C:\Users\<你的用户名>\AppData\Local\Microsoft\Edge\User Data\Default\Extensions
```

3. 打开 Chrome 的 `chrome://extensions/`，右上角打开 **「开发者模式」**，点 **「加载已解压的扩展程序」**，选中第 2 步那个**版本号目录**（注意是版本号那一层，不是它的上一层）。

**副作用先讲清楚**：这样装出来的扩展**不会自动更新**，我发新版本你得手动重来一遍。嫌麻烦的话，直接用 Edge 就行——它本来就是 Chromium，B站 照看，性能也没差。

> 冷知识：Edge 反而支持**直接从 Chrome 网上应用店安装扩展**（打开商店页顶部会有"允许来自其他商店的扩展"）。所以在扩展生态上，Edge 是更宽松的那一个。

## 四、做这个工具，最磨人的几件事

这部分不讲代码，只讲这个工具做起来最别扭的几个地方——想抄思路的同学可以当避雷清单看。

**① B站活动页的内容，是"慢慢长出来"的。**
它不是一次性渲染完的，所以"去页面上找一个元素"这件事本身就有讲究：去早了扑空，去晚了还得处理时序，主打一个急不得。

**② 官方接口只给标签，不给分类。**
想让你按"影视 / 游戏 / 美食"筛选，就得把标签翻译成分类。而活动标题里塞满了"联名""第三期""限时"这类噪音词，翻译起来相当容易翻车。

**③ "参赛门槛"和"奖励类型"，接口里根本没有。**
它们只能从标签和描述文本里推断出来。所以工具里那些"投稿即参与 / 低 / 中 / 高"，以及"现金瓜分 / 固定奖金 / 流量扶持 / 周边抽奖"——**都是算出来的，不是抄来的**。

**④ 扩展失效的时候，它不报错。**
这是最磨人的一点：

![最磨人的一点](./assets/05-bug.png)

一旦加载时机没对上、或者页面结构变了，最典型的现象就是——**工具栏压根不出现，控制台也一片安静**。你甚至分不清它是"没加载"还是"加载了但没跑起来"。

**⑤ 看起来像 A，实际是 B。**
比如控制台报的是跨域，实际是后端服务根本没起来。"排查方向跑偏"，大概是每个做工具的人都要交的学费。

## 五、写在最后

这个项目从头到尾没什么高深技术，解决的是一个特别小、特别具体的问题：

**让一个 UP 主在 10 秒内知道"今天该投哪个活动"。**

我一直觉得，个人开发者最有价值的产出，往往不是"又一个框架"，而是**"我自己每天都要用，而且市面上没有"**的小工具。

毕竟卷不过别人，咱可以卷工具嘛。

> 用一句话总结这个项目的定位：
> **它不生产内容，它只是内容的搬运工——但搬得很有品味。**
