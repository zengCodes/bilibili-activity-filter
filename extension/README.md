# B站活动筛选助手 - 浏览器插件

在B站活动列表页面直接注入筛选工具栏，智能匹配适合你的投稿活动，无需启动后端服务。

## 功能特性

- **页面内筛选**：直接在B站活动列表页注入筛选工具栏，不离开页面
- **实时数据**：同源调用B站API，获取最新173+活动，无CORS问题
- **多维度筛选**：分类、时间、奖励类型、关键词搜索
- **智能匹配**：设置你的视频类型，自动高亮高匹配活动
- **即将截止提醒**：剩余7天内的活动标记"即将截止"
- **Popup快览**：点击插件图标查看即将截止的活动，一键跳转投稿
- **设置同步**：筛选偏好和视频类型通过chrome.storage同步

## 安装方法

### 开发者模式加载（推荐）

1. 打开 Chrome / Edge 浏览器
2. 地址栏输入 `chrome://extensions/`（Edge是 `edge://extensions/`）
3. 右上角开启「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本目录：`extension/`
6. 插件加载成功，工具栏会出现粉色"B"图标

### 固定到工具栏

1. 点击浏览器右上角拼图图标
2. 找到「B站活动筛选助手」
3. 点击图钉图标固定到工具栏

## 使用方法

### 1. 浏览活动页面

访问 [B站有奖活动中心](https://www.bilibili.com/blackboard/era/reward-activity-list-page.html#/list)

页面顶部会自动注入粉色筛选工具栏：

```
┌─────────────────────────────────────────────────┐
│ 🎬 B站活动筛选助手    共173个 | 进行中173 | 本周截止12 │
│ 分类: [全部] [游戏] [动画] [音乐] [影视] [知识]...    │
│ 时间: [全部] [本周截止] [本月截止] [长期]            │
│ 奖励: [全部] [现金瓜分] [固定奖金] [流量扶持]        │
│ [搜索活动...] [我的视频类型: 影视解说] [排序▼]       │
└─────────────────────────────────────────────────┘
```

### 2. 设置视频类型

在「我的视频类型」输入框填写你的视频主题，如：
- `影视解说`
- `生活vlog`
- `美食制作`
- `游戏攻略`
- `知识科普`

系统会自动计算每个活动的匹配度，**匹配度≥50%的活动会高亮绿色边框**。

### 3. 筛选和排序

- 点击分类按钮筛选活动类型（支持多分类交集，一个活动可属于多个分类）
- 按时间筛选（本周截止/本月截止/长期）
- 按奖励类型筛选（现金瓜分/固定奖金/流量扶持）
- 搜索框输入关键词过滤
- 下拉选择排序方式（截止时间/匹配度）

### 4. 查看活动详情

点击活动卡片直接打开活动详情页投稿。

卡片显示：
- 活动名称和分类标签
- 活动时间和剩余天数
- 投稿话题标签和分区
- 奖励类型和说明
- 匹配度百分比

### 5. Popup快览

点击浏览器工具栏的插件图标，弹出小窗口：
- 查看活动总数、进行中、本周截止统计
- 设置视频类型（同步到页面）
- 查看14天内即将截止的活动列表
- 一键打开B站活动页面

## 文件结构

```
extension/
├── manifest.json      # 插件配置（Manifest V3）
├── background.js      # Service Worker，API请求和数据处理
├── content.js         # 注入B站页面的脚本，筛选工具栏和活动列表
├── content.css        # 注入页面的样式
├── popup.html         # 插件弹窗页面
├── popup.js           # 弹窗逻辑
├── popup.css          # 弹窗样式（内联在html中）
└── icons/             # 插件图标
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

## 工作原理

```
用户访问B站活动页面
        ↓
content.js 注入页面
        ↓
向 background.js 请求活动数据
        ↓
background.js 调用B站API（同源，无CORS）
  - 自动分页获取全部活动（4页×50条）
  - 数据清洗：时间戳转换、分类推断、奖励类型识别
        ↓
返回格式化数据给 content.js
        ↓
渲染筛选工具栏 + 自定义活动列表
        ↓
用户筛选/排序/搜索，实时更新列表
```

## 与Web版本的区别

| 特性 | 浏览器插件 | Web版本（需启动后端） |
|------|-----------|---------------------|
| 安装 | 加载解压扩展 | npm install && npm start |
| 数据获取 | 同源API调用 | 后端代理 |
| 使用场景 | 直接在B站页面操作 | 独立页面 |
| CORS问题 | 无（同源） | 后端解决 |
| 设置同步 | chrome.storage | 本地存储 |
| 离线可用 | 否（需访问B站） | 是（有fallback数据） |

**推荐组合**：日常浏览用插件（方便），深度筛选用Web版本（功能更全）。

## 常见问题

**Q: 页面没有出现筛选工具栏？**
A: 刷新页面，或检查插件是否已启用。content script只在活动列表页面注入。

**Q: 活动数量和B站页面不一致？**
A: 插件通过API获取全部活动（含已结束的），并自动过滤已结束活动。B站页面可能只显示部分。

**Q: 匹配度是怎么计算的？**
A: 根据你输入的视频类型，匹配活动的标题、标签、适合类型、描述，加权计算相似度。

**Q: 如何更新插件？**
A: 修改代码后，在 `chrome://extensions/` 页面点击插件的「刷新」按钮即可。
