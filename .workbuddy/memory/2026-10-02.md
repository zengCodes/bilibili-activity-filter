**技术备注（可复用）**：

- 本机 managed Python 3.13.12 自带 Pillow 12.2.0，但**没有** matplotlib / cairosvg / requests。
  → 画信息图直接用 Pillow `ImageDraw` + `C:/Windows/Fonts/msyh.ttc`（微软雅黑）、`msyhbd.ttc`（粗）、
  `consola.ttf`（等宽）即可，不需要装额外依赖。
- Pillow 渲染中文时**emoji 会变成方框**（如 ⚠），要么改文字描述，要么用手绘图形代替。
- AI 出图（ImageGen）右下角带「AI生成 / WORKBUDDY」水印，尺寸 1536×1024 时位于底部约 84px 内，
  裁掉底部 84px 即可去除。

**内容策略备注**：推广文里 🏀 彩蛋（代码中特判鬼畜/唱跳/rap/篮球标签）**故意写成含蓄表述**，
